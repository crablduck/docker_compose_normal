# Kafka 外部应用连接指南

## 问题描述
外部应用连接 Kafka 时，Kafka 会返回内部容器名 `kafka` 作为 broker 地址，但外部应用无法解析这个容器名，导致连接失败。

## 解决方案

### 1. 配置说明
当前 Kafka 配置支持双监听器模式：
- **内部监听器**: `PLAINTEXT://kafka:9092` - 用于容器间通信
- **外部监听器**: `EXTERNAL://172.16.1.172:9092` - 用于外部应用连接

### 2. 连接配置

#### 容器内应用连接
```properties
# Spring Boot application.yml
spring:
  kafka:
    bootstrap-servers: kafka:9092
```

#### 外部应用连接
```properties
# Spring Boot application.yml
spring:
  kafka:
    bootstrap-servers: 172.16.1.172:9092
```

#### Java 客户端示例
```java
// 外部应用 Kafka 生产者配置
Properties props = new Properties();
props.put("bootstrap.servers", "172.16.1.172:9092");
props.put("key.serializer", "org.apache.kafka.common.serialization.StringSerializer");
props.put("value.serializer", "org.apache.kafka.common.serialization.StringSerializer");

KafkaProducer<String, String> producer = new KafkaProducer<>(props);
```

### 3. 环境配置

#### 修改外部访问地址
编辑 `.env` 文件：
```bash
# 修改为实际的服务器IP
KAFKA_EXTERNAL_HOST=你的服务器IP
KAFKA_EXTERNAL_PORT=9092
```

#### 重启服务
```bash
docker-compose down
docker-compose up -d
```

### 4. 网络配置验证

#### 检查端口是否开放
```bash
# 检查端口监听
netstat -tlnp | grep 9092

# 测试连接
telnet 172.16.1.172 9092
```

#### 防火墙配置
确保防火墙允许 9092 端口访问：
```bash
# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=9092/tcp
sudo firewall-cmd --reload

# Ubuntu
sudo ufw allow 9092
```

### 5. 常见问题排查

#### 问题1: 连接超时
**原因**: 防火墙阻止或网络不通
**解决**: 检查防火墙设置和网络连通性

#### 问题2: 无法解析 kafka 主机名
**原因**: 外部应用尝试连接内部容器名
**解决**: 确保使用外部IP地址 `172.16.1.172:9092`

#### 问题3: 端口映射错误
**原因**: docker-compose.yml 端口映射配置错误
**解决**: 确保端口映射为 `9092:9094`，ADVERTISED_LISTENERS 使用正确端口

### 6. 监控和管理

#### Kafka UI 访问
- 地址: http://172.16.1.172:10180
- 用于监控 topics、消费者组等

#### 命令行工具
```bash
# 进入 Kafka 容器
docker exec -it kafka bash

# 创建 topic
kafka-topics.sh --create --topic test-topic --bootstrap-server localhost:9092

# 列出 topics
kafka-topics.sh --list --bootstrap-server localhost:9092
```

### 7. 生产环境建议

1. **使用域名**: 配置 DNS 解析，使用域名替代 IP 地址
2. **SSL/TLS**: 启用加密传输保证数据安全
3. **认证授权**: 配置 SASL 认证机制
4. **监控告警**: 部署 Kafka 监控系统

### 8. 多环境配置

#### 开发环境
```bash
KAFKA_EXTERNAL_HOST=localhost
KAFKA_EXTERNAL_PORT=9092
```

#### 测试环境
```bash
KAFKA_EXTERNAL_HOST=test-server-ip
KAFKA_EXTERNAL_PORT=9092
```

#### 生产环境
```bash
KAFKA_EXTERNAL_HOST=prod-kafka.company.com
KAFKA_EXTERNAL_PORT=9092
```

## 总结

通过配置双监听器模式，Kafka 可以同时支持容器内部通信和外部应用访问。关键是确保：
1. ADVERTISED_LISTENERS 配置正确的外部地址和端口
2. 外部应用使用外部IP地址连接
3. 防火墙和网络配置允许访问
4. 端口映射配置正确

这样配置后，外部应用就能正常连接 Kafka 服务了。
